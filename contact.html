Contact & feedback

Found a lesson correction, accessibility issue, or broken link? Let us know.

Report an issue

Use the public GitHub issue tracker for site and lesson feedback. You’ll need a GitHub account to submit a report.

Open GitHub Issues

Useful details to include

  • The lesson title and page URL
  • A short description of the problem
  • Your browser or device if the problem is technical

Issues are public. Please don’t include passwords, private records, or personal information. A private contact channel is not available yet.
