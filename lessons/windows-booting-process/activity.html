Boot Sequence Incident Map

Diagnose four startup symptoms using the stage-by-stage model from the lesson.

Instructions

  1. For each scenario, identify the most likely boot stage.
  2. Explain which component should normally run at that stage.
  3. Propose two safe, reversible checks.
  4. Compare your reasoning with a partner or your instructor.

Scenarios

1. No boot device found

The firmware detects the SSD, but immediately reports that no bootable device exists.

2. BCD error code

Windows Boot Manager appears but reports that required boot configuration data is missing.

3. Crash during spinning dots

The Windows logo appears, then the computer restarts after a newly installed storage driver.

4. Blank desktop after sign-in

Credentials are accepted, but the taskbar and desktop icons never appear.

Deliverable

Create a five-column table: symptom, likely stage, responsible component, evidence, and first checks. Keep each proposed action non-destructive.
