Introduction to ESP32

Meet a capable microcontroller platform and prepare your first safe digital output circuit.

Updated September 14, 202612 min readIoT / Embedded Systems

Learning objectives

After completing the lesson, students should be able to:

  • Describe the ESP32 and a typical development board
  • Explain GPIO, digital input, and digital output
  • Identify the role of Wi-Fi and Bluetooth in IoT projects
  • Prepare Arduino IDE and reason through a basic LED program

The ESP32 is a family of microcontrollers designed for embedded and connected projects. Its combination of computing power, programmable pins, and integrated wireless radios makes it useful for sensors, automation, prototypes, and Internet of Things systems.

What is ESP32?

A microcontroller is a compact computer intended to control hardware. It runs a program repeatedly and interacts with the physical world through pins and peripherals. ESP32 devices typically include one or more processor cores, memory, timers, communication interfaces, Wi-Fi, and Bluetooth.

The development board

The bare ESP32 module is commonly mounted on a development board. The board adds practical features such as a USB interface, voltage regulation, reset and boot buttons, status LEDs, and header pins. Board layouts differ, so the exact pinout must always be checked before wiring.

Electrical safety: ESP32 GPIO generally uses 3.3 V logic and is not normally 5 V tolerant. Confirm the limits for your exact board and never connect an unknown voltage directly to a pin.

GPIO

GPIO means General-Purpose Input/Output. Software can configure a supported pin as an input, an output, or a signal for a peripheral such as I²C, SPI, UART, PWM, or analog conversion. Not every numbered pin is equally suitable; some are connected to flash memory or affect boot behavior.

Wi-Fi and Bluetooth

Wi-Fi lets an ESP32 join an IP network, exchange data with web services, or serve a local control page. Bluetooth supports shorter-range device communication; many projects use Bluetooth Low Energy to conserve power and exchange small amounts of data.

Arduino IDE setup

  1. Install the current Arduino IDE from its official source.
  2. Add Espressif's ESP32 board support using the Boards Manager instructions.
  3. Connect a data-capable USB cable.
  4. Select the exact board model and its serial port.
  5. Open a basic example, verify it, and upload.

If no port appears, check the cable first: many inexpensive USB cables provide power but omit data conductors.

Basic LED example

A blink program configures an LED pin as an output, drives it HIGH, waits, drives it LOW, and waits again. The resistor limits current. Some development boards have an onboard LED; others require an external LED and a suitable resistor.

const int ledPin = 2;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  digitalWrite(ledPin, HIGH);
  delay(500);
  digitalWrite(ledPin, LOW);
  delay(500);
}

Pin 2 is only an example. Use the LED pin specified for your board. Before powering an external circuit, confirm LED polarity, resistor value, ground connection, and GPIO assignment.
